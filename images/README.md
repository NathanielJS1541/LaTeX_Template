# Images

This directory contains all images used throughout the document. These images
can be used for both figures and as part of the fancy header.

It is recommended to name them in such a way that they are grouped by section,
for example prefixing images with the same number as the
[sections](../sections/), so section 1 images are all prefixed with `01_`. This
ensures they will all be grouped together and therefore easier to find.
